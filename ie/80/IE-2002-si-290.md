# S.I. No. 290/2002 - Marine Casualty Investigation Board (Establishment Day) Order 2002

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

I, Frank Fahey, Minister for the Marine and Natural Resources, in exercise of the powers conferred on me by [section 7](https://www.irishstatutebook.ie/2000/en/act/pub/0014/print.html#sec7) of the [Merchant Shipping (Investigation of Marine Casualties) Act 2000](https://www.irishstatutebook.ie/2000/en/act/pub/0014/print.html) (No. 14 of 2000), hereby order as follows:

###### 1.

1. This Order may be cited as the Marine Casualty Investigation Board (Establishment Day) Order 2002.

###### 2.

2. The 5 ^th day of June 2002 is hereby appointed as the day on which Bord Imscrúdú Taismí Muirí or, in the English language, the Marine Casualty Investigation Board, shall be established.

|  |  |
| --- | --- |
|  | Given under my Official Seal, 5^th June 2002 |
|  | **Frank Fahey,** Minister for the Marine and Natural Resources |
