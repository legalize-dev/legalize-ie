# S.I. No. 217/1989 - Postal Order (Inland) Amendment (No. 23) Scheme 1989

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

S.I. No. 217 of 1989.

POSTAL ORDER (INLAND) AMENDMENT (No. 23) SCHEME 1989.

AN POST, in exercise of the powers conferred on it by Section 70 of the Postal and Telecommunications Service Act, 1983 (no. 24 of 1983), and with the concurrence of the Minister for Communications, hereby makes the following Scheme:

###### 1.

1. This Scheme may be cited as the Postal Order (Inland) Amendment (No. 23) Scheme, 1989.

###### 2.

2. This Scheme shall operate with effect from 1st August 1989.

###### 3.

3. The [Interpretation Act, 1937](https://www.irishstatutebook.ie/1937/en/act/pub/0038/index.html) (No. 38 of 1937), applies to this Scheme.

###### 4.

4. The Postal Order (Inland) Regulations, 1905, are hereby amended by the substitution of the following for Regulation 4 (inserted by Regulation 4 of the Postal Order (inland) Amendment (No. 10) Regulations, 1971):

"4. Postal Orders shall be issued for the following sums, namely, 50p, 70p, £1, £1.50, multiples of one pound between £2 and £10 both inclusive, £20, £30, £40 and £50.

###### 5.

5. The Postal Order (Inland) Regulations 1905, are hereby amended by the substitution of the following for Regulation 5.

|  |  |
| --- | --- |
| "5. The poundage payable on postal orders shall be as follows:— |  |
| for an order with a value not exceeding £0.70 | 20p |
| For an order with a value of £1 but not exceeding £5 | 40p |
| For an order with the value of £6 and not exceeding £10 | 50p |
| For an order with the value of £20 not exceeding £50 | £1.00 |

GIVEN under the Common Seal of AN POST this 26th day of July 1989.

PRESENT when the Common Seal

of AN POST was affixed hereto:

**GERARD HARVEY,**

Director.

**JIM TREACY,**

Secretary.

An Post,

General Post Office,

Dublin 1.

I, RAY BURKE, Minister for Communications, hereby consent to the provisions of the foregoing scheme.

**RAY BURKE,**

GIVEN under my Official Seal this 27th day of July 1989.

**EXPLANATORY NOTE.**

This Scheme, which operates with effect from 1st August, 1989, provides for an increase in poundage on Postal Orders.
