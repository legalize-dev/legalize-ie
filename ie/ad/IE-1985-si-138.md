# S.I. No. 138/1985 - Money Order Amendment (No. 28) Scheme, 1985

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

S.I. No. 138 of 1985.

MONEY ORDER AMENDMENT (No. 28) SCHEME, 1985.

An Post in exercise of the powers conferred on it by [Section 70](https://www.irishstatutebook.ie/1983/en/act/pub/0024/sec0070.html#sec70) of the [Postal and Telecommunications Services Act, 1983](https://www.irishstatutebook.ie/1983/en/act/pub/0024/index.html) (No. 24 of 1983), and with the consent of the Minister for Communications, hereby makes the following Scheme:

###### 1.

1. This Scheme may be cited as the Money Order Amendment (No. 28) Scheme, 1985.

###### 2.

2. This Scheme shall come into operation on the 25th day of February, 1985.

###### 3.

3. The [Interpretation Act, 1937](https://www.irishstatutebook.ie/1937/en/act/pub/0038/index.html) (No. 38 of 1937), applies to this Scheme.

###### 4.

4. In this Scheme:—

"the Principal Regulations" means the Money Order regulations, 1903;

"the Regulations of 1982" means the Money Order Amendment (No. 27) Regulations 1982 ( [S.I. No. 61 of 1982](https://www.irishstatutebook.ie/1982/en/si/0061.html) ).

###### 5.

5. Regulation 18 (1) of the Principal Regulations, is hereby amended by the substitution of the following tables for Tables A, B and C (inserted by Regulation 5 of the Regulations of 1982) which set out the poundage payable in respect of money orders:

> "

|  |  |
| --- | --- |
| A | Poundage |
| In respect of inland money orders: for an amount not exceeding £50.00 | 100p |
| for an amount exceeding £50 but not exceeding £100.00 | 150p |

|  |  |
| --- | --- |
| B | Poundage |
| In respect of foreign money orders: |  |
| for an amount not exceeding £25.00 ... ... ... | 150p |
| for an amount exceeding £25.00 but not exceeding £50 | 225p |

|  |  |
| --- | --- |
| C | Poundage |
| In respect of supplementary services: |  |
| for correcting or altering the name of the remitter or payee | 100p |
| for stopping payment ... ... ... ... ... |  |
| 100p |  |
| for the issue of a duplicate money order ... ... ... ...(including stopping payment of the original order) | 100p |
| for the renewal of a void money order ... ... ... | 100p |
| for an advice or certificate of payment of an inland money order ... ... ... ... ... ... ... | 25p |
| for an advice or certificate of payment of a foreign money order ... ... ... ... ... ... ... | 25p |

> "

###### 6.

6. Regulation 25 of the Principal Regulations, as amended by Regulation 6 of the Regulations of 1982 is hereby amended by the substitution of "a supplementary fee of twenty five pence" for "a supplementary fee of four new pence".

###### 7.

7. Regulation 26 of the Principal Regulations (inserted by Regulation 7 of the Regulations of 1982) is hereby amended by the substitution of "twenty-five pence" for "fifteen new pence".

EXPLANATORY NOTE

This Scheme applies to the Money Order service and comes into operation on the 25th February, 1985. It authorises increases in charges on inland and foreign money orders, telegraph money orders and in other miscellaneous charges.
