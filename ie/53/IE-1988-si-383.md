# S.I. No. 383/1988 - Postal Order (Inland) Amendment (No. 21) Scheme, 1988

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

S.I. No. 383 of 1988.

POSTAL ORDER (INLAND) AMENDMENT (No. 21) SCHEME, 1988.

AN POST, in exercise of the powers conferred on it by [Section 70](https://www.irishstatutebook.ie/1983/en/act/pub/0024/sec0070.html#sec70) of the [Postal and Telecommunications Services Act, 1983](https://www.irishstatutebook.ie/1983/en/act/pub/0024/index.html) (No. 24 of 1983), and with the consent of the Minister for Communications, hereby makes the following Scheme:

###### 1.

1. This Scheme may be cited as the Postal Order (Inland) Amendment (No. 21) Scheme, 1988.

###### 2.

2. This Scheme shall operate with effect from the 7th day of March, 1988.

###### 3.

3. The [Interpretation Act, 1937](https://www.irishstatutebook.ie/1937/en/act/pub/0038/index.html) (No. 38 of 1937), applies to this Scheme.

###### 4.

4. The Postal Order (Inland) Regulations, 1905, are hereby amended by the substitution of the following for Regulation 5 (inserted by Regulation 4 of the Postal Order (Inland) Amendment (No. 19) Regulations, 1985 ( [S.I. No. 136 of 1985](https://www.irishstatutebook.ie/1985/en/si/0136.html) ),):

"5. The poundage payable on postal orders shall be as follows:

|  |  |
| --- | --- |
| For an order with a value not exceeding £0.95 ... ... ... ... ... ... | 20p |
| for an order with a value of £1 but not exceeding £10 ... ... ... ... | 33p |
| For an order with a value of £20 ... ... | 55p" |

GIVEN under the Common Seal of AN POST this 27th day of October, 1988.

Present when the Common Seal of AN POST was affixed hereto:—

|  |  |
| --- | --- |
|  | G. P. HARVEY, Director. |
| MICHAEL COADY, Controller Corporate Affairs. | JIM TREACY, Secretary. |

An Post,

General Post Office,

Dublin 1.

I, RAY BURKE, Minister for Communications, hereby consent to the provisions of the foregoing scheme.

GIVEN under my Official Seal this 22nd day of December, 1988.

**RAY BURKE,**

Minister for Communications.

**EXPLANATORY NOTE.**

This Scheme, which operates with effect from the 7th March, 1988, increases the poundage on postal orders.
