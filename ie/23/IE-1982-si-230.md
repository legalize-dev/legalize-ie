# S.I. No. 230/1982 - Coras Beostoic agus Feola (Levy on Exported Livestock) (Amendment) Regulations, 1982

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

S.I. No. 230 of 1982.

CORAS BEOSTOIC AGUS FEOLA (LEVY ON EXPORTED LIVESTOCK) (AMENDMENT) REGULATIONS, 1982.

I, BRIAN LENIHAN, Minister for Agriculture, in exercise of the powers conferred on me by [section 29](https://www.irishstatutebook.ie/1979/en/act/pub/0025/sec0029.html#sec29) (6) of the [Coras Beostoic agus Feola Act, 1979](https://www.irishstatutebook.ie/1979/en/act/pub/0025/index.html) (No. 25 of 1979), hereby make the following Regulations:—

###### 1.

1. These Regulations may be cited as the Coras Beostoic agus Feola (Levy on Exported Livestock) (Amendment) Regulations, 1982.

###### 2.

2. These Regulations shall come into operation on the 26th day of July, 1982.

###### 3.

3. Regulation 4 of the Coras Beostoic agus Feola (Levy on Exported Livestock) Regulations, 1979 ( [S.I. No. 324 of 1979](https://www.irishstatutebook.ie/1979/en/si/0324.html) .), is hereby amended by the substitution for the Table thereto of the following Table.

TABLE

|  |  |
| --- | --- |
| 1p | Salmon |
| 2p | Tan |
| 5p | Pink |
| 10p | Deep Yellow |
| 20p | Cyan |
| 50p | Orange |
| £1 | Blue |
| £2 | Grey |
| £5 | Yellow |
| £10 | Mauve |
| £20 | Cream |

GIVEN under my Official Seal, this 21st day of July, 1982.

**BRIAN LENIHAN,**

Minister for Agriculture.

**EXPLANATORY NOTE.**

These Regulations prescribe the denominations of the adhesive stamp by means of which levy is required to be paid in respect of livestock exported live from the State.
