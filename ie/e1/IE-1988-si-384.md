# S.I. No. 384/1988 - Postal Order (Inland) Amendment (No. 22) Scheme, 1988

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

S.I. No. 384 of 1988.

POSTAL ORDER (INLAND) AMENDMENT (No. 22) SCHEME, 1988.

AN POST, in exercise of the powers conferred on it by Section 70 of the Postal and Telecommunications Service Act, 1983 (No. 24 of 1983), hereby makes the following Scheme:

###### 1.

1. This Scheme may be cited as the Postal Order (Inland) Amendment (No. 22) Scheme, 1988.

###### 2.

2. This Scheme shall operate with effect from the 22nd day of September, 1988.

###### 3.

3. The [Interpretation Act, 1937](https://www.irishstatutebook.ie/1937/en/act/pub/0038/index.html) (No. 38 of 1937) applies to this Scheme.

###### 4.

4. The Postal Order (Inland) Regulations, 1905, are hereby amended by the substitution of the following for Regulation 4 (inserted by Regulation 4 of the Postal Order (Inland) Amendment (No. 10) Regulations, 1971 ( [S.I. No. 34 of 1971](https://www.irishstatutebook.ie/1971/en/si/0034.html) )): and Regulation 5 inserted by Regulation 4 of Postal Order (Inland) Amendment (No. 21) [S.I. No. 383 of 1988](https://www.irishstatutebook.ie/1988/en/si/0383.html) ):

"4. Postal Orders shall be issued for the following sums namely 50p, 70p, £1, £1.50, multiples of one pound between £2 and £10 both inclusive, £20, £30, £40 and £50.

"5. The poundage payable on postal orders shall be as follows:

|  |  |
| --- | --- |
| For an order with a value not exceeding £0.95 ... ... ... ... ... ... | 20p |
| For an order with a value of £1 but not exceeding £10 ... ... ... ... ... | 33p |
| For an order with a value of £20 ... ... | 55p |
| For an order with a value of £30 ... ... | 85p |
| For an order with a value of £40 or £50 | £1.00p |

Given under the Common Seal of AN POST this 22nd day of December, 1988.

Present when the Common Seal of AN POST was affixed hereto:

|  |  |
| --- | --- |
|  | GERARD HARVEY, Director. |
| MICHAEL COADY, Corporate Affairs. | JIM TREACY, Secretary. |

An Post,

General Post Office,

Dublin 1.

**EXPLANATORY NOTE.**

This Scheme, which operates with effect from 22nd September, 1988 provides for the introduction of postal orders of the value £30, £40 and £50.
