# S.I. No. 136/1985 - Postal Order (Inland) Amendment (No. 19) Scheme, 1985

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

S.I. No. 136 of 1985.

POSTAL ORDER (INLAND) AMENDMENT (No. 19) SCHEME, 1985.

An Post, in exercise of the powers conferred on it by Section 70 of the Postal and Telecommunications Services Act. 1983 (No. 24 of 1983) and with the consent of the Minister for Communications, hereby makes the following Scheme:

###### 1.

1. This Scheme may be cited as the Postal Order (Inland) Amendment (No. 19) Scheme. 1985.

###### 2.

2. This scheme shall come into operation on the 25th day of February. 1985.

###### 3.

3. The [Interpretation Act, 1937](https://www.irishstatutebook.ie/1937/en/act/pub/0038/index.html) (No. 38 of 1937), applies to this Scheme.

###### 4.

4. The Postal Order (Inland) Regulations, 1905 are hereby amended by the substitution of the following for Regulation 5 (inserted by Regulation 4 of the Postal Order (Inland) Amendment (No. 18) Regulations, 1982 ( [S.I. No. 62 of 1982](https://www.irishstatutebook.ie/1982/en/si/0062.html) )):

"5. The poundage payable on postal orders shall be as follows:

|  |  |
| --- | --- |
| For an order with a value not exceeding £0.95... | 15p |
| For an order with a value in excess of £0.95..... | 20p" |

**EXPLANATORY NOTE.**

This Scheme, which comes into operation on the 25th February. 1985. provides for amending the poundage on postal orders.
