# I.R. Uimh. 61/1986 -An tOrdú Staidrimh (Daonáireamh), 1986

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

De bhun na gComhachtaí a thugtar dom le hailt 11 agus 16 den Acht Staitistíochta, 1926 (Uimh. 12 de 1926), agus leis an Ordú um na hAchta Staidrimh, 1926 agus 1946 (Feidhmeanna Aire d'Aistriú), 1949 (I.R. Uimh. 142 de 1949), agus leis an Ordú Staidrimh (Feidhmeanna Aire a Tharmligean),1983 (I.R. Uimh. 13 de 1983), ordaímse SEÁN O'BAIRÉAD, Aire Stáit ag Roinn an Taoisigh, leis seo, mar a leanas:—

###### 1.

1. An tOrdú Staidrimh (Daonáireamh), 1986, is teideal don Ordú seo.

###### 2.

2. Baineann an tAcht Léiriúcháin, 1937 (Uimh. 38 de 1937), leis an Ordú seo.

###### 3.

3. San Ordú seo—

ciallaíonn "an tAcht" an tAcht Staitistíochta, 1926 (Uimh. 12 de 1926);

ciallaíonn "an staidreamh" an staidreamh a shonraítear in Airteagal 4 den Ordú seo.

###### 4.

4. Baileofar staidreamh arb iad seo a leanas is ábhar, cineál agus gné dó is é sin le rá:

( *a* ) Daonrá;

( *b* ) Ainmneacha, gnéas agus an dáta a rugadh;

( *c* ) Staid maidir le pósadh, gaol leis an gceann teaghlaigh;

( *d* ) An áit a rugadh;

( *e* ) Eolas ar an nGaeilge;

( f ) Gnátháit chónaithe agus gnátháit chónaithe bliain roimh an 13 Aibreán, 1986;

( *g* ) An tír ina raibh an áit chónaithe dheireanach roimhe sin agus an bhliain a ndeachthas chun cónaithe in Éirinn;

( *h* ) Gnáthchóir thaistil ón áit chónaithe chun an ionaid oibre nó chun scoile agus fad an aistir;

( *i* ) Stádas faoi láthair, slí bheatha faoi láthair, stádas fostaíochta faoi láthair, an líon fostaithe, fostóir faoi láthair agus gnó an fhostóra sin;

( *j* ) Seoladh an ionaid oibre, na scoile nó an choláiste;

( *k* ) An aois ar scoir oideachas lánaimseartha;

( *l* ) Na cáilíochtaí eolaíochta no teicneolaíochta atá ag an duine;

( *m* ) I gcás teaghlaigh phríobháideacha — an méid seomraí a áitítear agus an méid gluaisteán a úsáidtear go heisiatach ag daoine a bhfuil gnáthchónaí orthu sa teaghlach;

amhail mar bhí oíche Dé Domhnaigh, an 13ú lá d'Aibreán 1986 agus an mhaidin dár gcionn.

###### 5.

5. Is iad seo a leanas na daoine, nó na haicmí daoine, a mbeidh orthu tuairisceáin no faisnéis a thabhairt chun críocha an staidrimh, is é sin le rá:

( *a* ) ceann teaghlaigh phríobháidigh nó an duine eile atá ag gníomhú mar cheann teaghlaigh phríobháidigh;

( *b* ) an duine atá i bhfeighil forais, mar atá, óstán, club, teach aíochta, brú, teach iostais, teach lóistín, scoil chónaithe, coláiste, clochar, mainistir, beairic, príosún, ospidéal, teaghlach contae, teach banaltrais, nó aon bhunaíocht eile d'aon saghas;

( *c* ) an máistir nó an duine eile atá i bhfeighil árthaigh in aon chuan, calafort, bá, góilín, nó ar aon loch, abhainn nó canáil nó in aon áit eile ar uiscí laistigh de dhlínse an Stáit;

( *d* ) daoine aonair.

###### 6.

6. (1) Tabharfar tuairisceáin agus faisnéis agus baileofar an staidreamh ar an modh a thuairiscítear i bhFoirm A, Foirm A (P) agus Foirm D atá leagtha amach i gCuid 1 den Sceideal a ghabhann leis an Ordú seo.

- (2) Is daoine a cheapfar faoin Ordú seo chun bheith ina noifigigh staidrimh a dhéanfaidh an staidreamh a bhailiú, a fhíorú agus a choimriú agus beidh gach duine a cheapfar amhlaidh ceaptha agus aitheanta mar Oifigeach Ceangail Daonáirimh, mar Mhaoirseoir Réigiúin Daonáirimh, mar Mhaoirseoir Seachtrach Daonáirimh nó mar Áiritheoir Daonáirimh, de réir mar a bheidh.

###### 7.

7. (1) Féadfaidh Coimisinéir an Gharda Síochána cibé daoine agus cibé líon daoine (comhaltaí den Gharda Síochána) is oiriúnach leis a cheapadh mar oifigigh staidrimh chun críche an Ordaithe seo agus féadrar ceapadh daoine faoin mír seo a dhéandmh faoina n-ainmneacha nó faoi theideal a gcéime nó i cibé slí idir-dhealaitheach eile is oiriúnach leis an gCoimisinéir sin.

- (2) Tabharfar do gach duine a cheapfar faoin mír seo deimhniú i scríbhinn a bheidh sínithe ag Ceannfort den Gharda Síochána, á dheimhniú go bhfuil an duine sin ag gníomhú mar oifigeach staidrimh chun críocha an Ordaithe seo.

###### 8.

8. (1) Féadfaidh an tAire Stáit ag Roinn an Taoisigh cibé daoine agus cibé líon daoine is oiriúnach leis a cheapadh chun bheigh ina n-oifigigh staidrimh chun críche an Ordaithe seo, agus féadfar ceapadh daoine faoin mír seo a dhéandmh faoina n-ainmneacha nó i cibé slí' idirdhealaitheach eile is oiriúnach leis an Aire Stáit sin.

- (2) Is san fhoirm a shonraítear i gCuid II den Sceideal a ghabhann leis an Ordú seo a bheidh an ceapachán a cheanglaítear a thabhairt faoin Acht do dhuine a cheapfar faoin mír seo agus beidh sé sínithe de réir cheanglais an Achta.

###### 9.

9. Úsáidfear na foirmeacha atá leagtha amach i gCuid I den Sceideal a ghabhann leis an Ordú seo chun an staidreamh a bhailiú.

###### 10.

10. Ní bheidh feidhm ag an Ordú um Oifigigh Staitistíochta (Ceapachán), 1926, maidir le ceapadh daoine mar oifigigh staidrimh chun críocha an Ordaithe seo.

AN SCEIDEAL

Form A (P) — Census of Population of Ireland, 1986.

NÓTA MÍNIÚCHÁIN.

Is é is cuspóir don ionstraim seo cumhacht a thabhairt chun daonáireamh reachtúil a dhéanamh an 13 Aibreán, 1986, chun scóip an Daonáirimh a shainmhíniú agus chun na foirmeacha a úsáidfear agus na daoine, nó na haicmí daoine, a mbeidh orthu tuairisceáin nó eolas a thabhairt chun críche an Daonáirimh, a ordú.
