# I.R. Uimh. 360/1982 -An tOrdú Staidrimh (Móráireamh ar Fhoirgníocht agus ar Thógáil), 1982

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

De bhun na gcumhachtaí a thugtar le halt 16 (1) den Acht Staitistíochta, 1926 (Uimh. 12 de 1926) agus leis an Ordú um na hAchta Staidrimh, 1926 agus 1946 (Feidhmeanna Aire d'Aistriú), 1949 (I.R. Uimh. 142 de 1949) agus leis an Ordú Staidrimh (Cumhachtaí agus Dualgais a Tharmligean) 1982 (I.R. Uimh. 97 de 1982), ordaímse PHARALÁN Ó hEACTHAIRN, Aire Stáit ag Roinn an Taoisigh, leis seo, mar a leanas:—

###### 1.

1. An tOrdú Staidrimh (Móráireamh ar Fhoirgníocht agus ar Thógáil), 1982, is teideal don Ordú seo.

###### 2.

2. Baineann an tAcht Léiriúcháin, 1937 (Uimh. 38 de 1937), leis an Ordú seo.

###### 3.

3. Baineann an tOrdú seo le gnóthais atá ag gabháil d'obair fhoirgníochta agus thógála lena n-airítear mórbhealaí, séaracht, draenáil agus oibreacha eile den chineál céanna.

###### 4.

4. Baileofar sa bhliain 1982 staidreamh (dá ngairtear "an staidreamh" san Ordú seo), maidir leis na gnóthais lena mbaineann an tOrdú seo, i dtaobh na nithe ar leithligh atá leagtha amach i gCuid I den Sceideal a ghabhann leis seo.

###### 5.

5. Is iad na foirmeacha a thaispeántar i gCuid II den Sceideal a ghabhann leis seo na foirmeacha a úsáidfear chun an staidreamh a bhailiú, agus tá sraith díobh sin, agus iad sínithe ag an Aire Stáit ag Roinn an Taoisigh taiscthe i Roinn an Taoisigh.

###### 6.

6. Is é an duine ag a mbíonn an gnóthas ar siúl, agus ar a ndéanfar leoréileamh faoi alt 8 (1) den Acht Staitistíochta, 1926 (Uimh. 12 de 1926) a thabharfaidh tuairisceáin agus eolas chun críche an staidrimh, maidir le haon ghnóthas lena mbaineann an tOrdú seo.

AN SCEIDEAL

CUID I

Is leis an mbliain 1981 a bhaineann ábhar na Coda seo (ach amháin mar a n-éilíonn an comhthéacs a mhalairt).

EOLAS, TUAIRISCEÁIN AGUS SONRAÍ

- (A) Do ghnóthais a ndéantar leor-éileamh ina leith faoi alt 8 (1) den Acht Staitistíochta, 1926, ar an bhfoirm a shonraítear i gCuid II den Sceideal seo ag uimhir thagartha 1.

*Uimh. 1 — Athruithe ar na Sócmhainní Caipitil*

A—Méaduithe ar na Sócmhainní Caipitil agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Costas gléasra, innealra agus trealaimh (gan feithiclí a áireamh) a cuireadh isteach.

( *b* ) Costas feithiclí a ceannaíodh.

( *c* ) Costas foirgneamh nua.

( *d* ) Costas foirgneamh a bhí ann.

( *e* ) Costas talaimh.

( *f* ) Gach sóchmhainn chaipitil eile.

B—Laghduithe ar na Sócmhainní Caipitil Dochta i rith na bliana agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Luach díolachán gléasra, innealra agus trealaimh.

( *b* ) Luach díolachán feithiclí.

( *c* ) Luach díolachán foirgneamh.

( *d* ) Luach diolachán talaimh.

( *e* ) Luach díolachán gach sócmhainn chaipitil eile.

*Uimh. 2 — Stoic ar láimh agus Obair idir lámha*

Luach stoc agus obair idir lámha i dtús agus i ndeireadh na bliana, agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Stoic ábhar, comhpháirteanna, breosla.

( *b* ) Obair idir lámha.

( *c* ) Stoic d'earraí críochnaithe a rinne an gnóthas réidh lena ndíol.

( *d* ) Stoic d'earraí a ceannaíodh lena n-athdhíol gan tuilleadh próiseála.

*Uimh. 3 — Láimhdeachas*

Láimhdeachas iomlán an ghnóthais i gcaitheamh na bliana agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Obair a rinneadh mar phríomh-chonraitheoir (lena n-áirítear obair a rinne fochonraitheoirí don ghnóthas) agus idirdhealú a dhéanamh idir obair fhoirgníochta agus obair thógála eile.

( *b* ) Obair a rinneadh mar fhochonraitheoir.

( *c* ) Earraí a rinneadh agus a díoladh i rith na bliana nó a cuireadh le stoc i ndeireadh na bliana.

( *d* ) Díolachán earraí a ceannaíodh lena n-athdhíol gan tuilleadh próiseála.

( *e* ) Gach fáltas eile.

*Uimh. 4 — Ceannach Breosla, agus Leictreachas*

Sonraí i dtaobh costais peitriliam, olaí, gáis, leictreachais agus breoslaí eile a ceannaíodh.

*Uimh. 5 — Ceannach Ábhair Fhoirgníochta*

Costas na n-ábhar uile a cheannaigh an gnólacht.

*Uimh. 6 — Íocaíochtaí le Fochonraitheoirí*

Íocaíochtaí ar obair a rinneadh i gcaitheamh na bliana don ghnóthas ag gnólachtaí eile ar chonarthaí a foligeadh chucu i ndáil leis an obair a n-éilítear sonraí ina taobh faoi Uimh. 3 thuas, agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Íocaíochtaí ar obair a rinne daoine a bhí ag obair de réir fhochonartha saothair amháin.

( *b* ) Íocaíochtaí ar obair a rinne fochonraitheoirí eile.

*Uimh. 7 — Costas Earraí Eile agus Seirbhísí*

Costas earraí eile agus seirbhísí agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Seirbhísí tionsclaíocha a soláthraíodh don ghnólacht ag daoine eile (mar shampla, obair dheisiúcháin agus cothabhála, obair séirbhise agus suiteála, taighde etc).

( *b* ) Costas earraí a ceannaíodh lena n-athdhíol gan tuilleadh próiseála.

( *c* ) Gléasra, innealra, scafall agus trealamh eile a fhruiliú.

( *d* ) Cíosanna a íocadh ar áitribh.

( *e* ) Préimheanna árachais a íocadh ar ghléasra, ar fheithiclí agus ar áitribh.

( *f* ) Muirir bhainc (gan muirir úis a áireamh).

( *g* ) Ábhair eile agus seirbhísí tionsclaíocha eile.

*Uimh. 8 — Cánach Indíreacha*

( *a* ) Ab iníoctha

- (i) CBL a muirearaíodh ar an láimhdeachas iomlán.

- (ii) Dleacht mháil a íocadh nó ab iníoctha.

- (iii) Gach cáin indíreach eile a íocadh nó ab iníoctha.

( *b* ) Ab inasbhainte

- (i) CBL ab inasbhainte ar cheannach breoslaí, ábhar etc.

- (ii) CBL ab inasbhainte ar cheannach Sócmhainní Caipitil.

*Uimh. 9 — Fostaíocht agus tuarastal/Pá a íocadh*

*Daoine ar Fostú*

An méid daoine a bhí ag obair iarbhír nó ar laethanta saoire le pá sa ghnóthas ar feadh na seachtaine pá nó le linn aon chuid den tseachtain phá dar chríoch an 19 Meán Fómhair, 1981, nó an dáta ionadaitheach is gaire dó sin, agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Dílseánaigh.

( *b* ) Fostaithe bainistíochta agus teicníochta (lena n-áirítear stiúrthóirí oibre).

( *c* ) Foireann chléireachais agus foireann eile oifige:

—Fir

—Mná.

( *d* ) Bunfhoireann mhaoirseachta (lena n-áirítear saoistí agus maoir).

( *e* ) Oibrithe oilte.

( *f* ) Printísigh.

( *g* ) Oibrithe neamhoilte nó breacoilte:—

—ar rátaí pá aosach

—ar rátaí pá ógánach.

( *h* ) Daoine a bhí ag obair de réir fochonartha "saothar amháin".

*Uimh. 10 — Costais Saothair Eile*

Costais saothair eile agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Ranníoc ÁSPC an fhostóra.

( *b* ) Íocaíochtaí iomarcaíochta cnapshuime lúide aisíocaíochtaí a fuarthas.

( *c* ) Íocaíochtaí lúide aisíocaíochtaí faoin Acht Oiliúna Tionscail (i.e. le hAnCO).

( *d* ) Ranníoc an fhostóra do chistí Aoisliúntais nó do Scéimeanna Pinsin eile.

( *e* ) Préimheanna árachas dliteanais fhostóra, árachas dliteanais phoiblí agus árachas sláinte fhostóra.

( *f* ) Costais saothair eile.

B. Do ghnóthais a ndéantar leor-éileamh ina leith faoi alt 8(1) den Acht Staitistíochta, 1926, ar an bhfoirm a shonraítear i gCuid II den Sceideal seo ag uimhir thagartha 2.

*Uimh. 1 — An cineál oibre a rinneadh*

Ceanglaítear sonraí a thabhairt ar an gcineál oibre a rinneadh.

*Uimh. 2 — Fáltais i leith obair a rinneadh i rith na bliana*

( *a* ) An t-ollmhéid a fuarthas sa bhliain ó chliaint roimh chostais a asbhaint (lena n-áiritear obair a rinne fochonraitheoirí don ghnóthas) agus idirdhealú a dhéanamh eatarthu seo a leanas:—

- (i) Tógáil nua, atógáil agus feabhsú teaghaisí.

- (ii) Obair thógála nua eile (lena n-áirítear feabhsúcháin agus atógáil).

- (iii) Obair dheisithe agus chothabhála.

( *b* ) An t-ollmhéid a fuarthas as obair a rinneadh mar fhochonraitheoir.

*Uimh. 3 — Fostaíocht agus Pá Tuarastail a íocadh*

An méid daoine a bhí ag obair iarbhír nó ar laethanta saoire le pá sa ghnóthas an tseachtain phá dar chríoch an 19 Meán Fómhair, 1981, nó an ghnáthsheachtain phá is gaire di sin, agus idirdhealú a dhéanamh eatarthu leo a leanas:—

( *a* ) Dílseánaigh/Úinéirí ag obair sa ghnó.

( *b* ) Foireann bhainistíochta, theicníochta agus chléireachais.

( *c* ) Daoine a bhí ag obair de réir fochonartha "saothair amháin".

( *d* ) Gach fostaí eile.

*Pá agus Tuarastail*

Ollmhéid an phá agus na dtuarastal a íocadh sa bhliain, agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Le fostaithe bainistíochta, teicníochta agus cléireachais.

( *b* ) Le gach fostaí eile.

*Uimh. 4 — Costais Eile*

Costais eile a tabhaíodh, agus idirdhealú a dhéanamh eatarthu seo a leanas:—

( *a* ) Ábhair, breoslaí agus leictreachas a ceannaíodh.

( *b* ) Íocaíochtaí le fochonraitheoirí (gan íocaíochtaí le fochonraitheoirí "saothair amháin" a áireamh).

( *c* ) Íocaíochtaí le fochonraitheoirí "saothair amháin".
